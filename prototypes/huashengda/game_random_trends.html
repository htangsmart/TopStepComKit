游戏排名 · 随机生成

在「排名与趋势」分区标题右侧加一个「🎲 随机」胶囊按钮。点一下就生成几条随机排名，发送条立即可用。左侧手机可以直接点。

原型控制

为什么放在分区标题右侧，而不是卡片内角

  • 红框位置在卡片的右上角，列表为空时会压到插画；有数据时第一行右边是趋势箭头，按钮会和它抢位置。
  • 分区标题这一行本来就放着 0 / 30，是“对这组数据操作”的位置，空列表和有数据时都能稳定出现。
  • 空列表时，插画下方还有一个「随机生成 5 条」主入口，第一次使用时更容易发现。

交互

  1. 列表为空：点「随机」直接生成（默认 5 条），不弹窗。按钮上的骰子会转一圈，新行依次滑入。
  2. 已有数据：弹出底部面板，可以选条数（3 / 5 / 10 / 25）和「包含边界值」，再选「替换」或「追加」。追加时跳过已有游戏，总数不超过 30。
  3. 随机出来的行带「随机」小标，发送成功后标签消失。
  4. 生成后底部提示「已生成 5 条 · 撤销」，4 秒内可以撤销，恢复到生成前的列表。
  5. 行点开后仍是原来的编辑界面，可以改排名和趋势。
  6. 「发送 N 条」沿用现在的 save 流程，不做改动。

随机规则

  • 游戏：从 25 种里随机选，不重复（kTSHsdGameTypeCount）。
  • 排名：1–99，偏向靠前的名次（取两个随机数中较小的），看起来更像真实数据。
  • 趋势：降 / 平 / 升，等概率。
  • 边界值打开时：至少 1 条排名为 0，至少 1 条为 255。

OC 实现要点（TSHsdGameVC）

  • 新增 ts_randomTrends：trends.count == 0 时直接调 ts_generateRandom:replace:，否则用 TSHsdSheet 弹出选项。
  • 用 arc4random_uniform 打乱 0..24 后取前 N 个；追加时先排除 used 里已有的游戏。
  • 撤销：生成前保存一份 trends 的深拷贝，toast 的撤销按钮用它恢复。
  • 「随机」标签：用一个 NSMutableSet<NSNumber *> *randomGameTypes 记录，save 成功后清空。
  • 文案新增到 hsd_*.strings：hsd.game.random、hsd.game.random_title、hsd.game.random_replace_format、hsd.game.random_append_format、hsd.game.random_done_format、hsd.game.random_edge。
