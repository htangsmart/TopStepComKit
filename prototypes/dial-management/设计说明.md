# 表盘管理页面设计

预览地址：http://127.0.0.1:8766/

交付为单文件 `index.html`，直接打开也可使用。复用用户提供的自定义表盘原型；所有设备数据、安装与删除均为模拟，不调用蓝牙。编辑草稿只保存到本机浏览器。原有 iOS 文件未修改。

## 视觉保持一致

- 原页面的系统中文字体、`#f6f5f2` 背景、`#252823` 文本、`#f16d43` 主按钮、浅橙选中态。
- 原页面手机容器、状态栏、表带、表壳、背景素材、编辑组件与底部弹层。
- 设备形状贯穿列表、详情、当前预览和编辑器；正式 App 由设备信息决定，原型通过说明页切换。
- 当前预览占据上半部；橙色“创建表盘”是主要入口，“导入表盘”为次要入口。
- 顶部标题固定，内容滚动，空间摘要固定在底部。长列表自然滚动，不挤压卡片。

## 信息结构与交互

1. 当前使用：表盘名称、类型、实物预览与连接状态。断开连接后明确标记为上次同步。
2. 创建表盘：照片、相册、视频、弹幕四种入口，进入复用的编辑器。
3. 导入表盘：延续已有云端文件安装能力，支持 `.dial / .bin / .zip / .tar`。没有虚构在线商城。
4. 手表中的表盘：全部、内置、云端、自定义分类。当前使用标记与顶部同步。
5. 草稿：来自手机本地，独立于设备安装列表；每类型一份，与现有 `TSDialEditorState` 保存结构一致。
6. 详情：点击卡片只预览，点击“设为当前表盘”才发起切换。处理中防重复点击；失败保留旧状态。
7. 管理：可删除项显示减号；内置项明确不可删除。删除前确认；若为当前表盘，先切换内置表盘，确认成功后才卸载。
8. 安装：准备 → 传输 → 确认结果 → 成功。可取消，可演示失败与重试。安装与切换分别确认。
9. 空间：展示剩余空间和安装数量；空间不足进入管理，保留创作内容供清理后重试。

## 与现有接口的对应

| 交互 | 接口 / 数据 | 接入注意 |
|---|---|---|
| 初始加载、刷新 | `fetchAllDials` + `fetchCurrentDial` | 区分成功空数组、查询失败、当前表盘未知；成功空数组必须清空旧列表 |
| 当前状态 | `TSDialModel.isCurrent` / `dialId` | 操作成功及回到前台后回查，以设备为准 |
| 分类 | `TSDialModel.dialType` | 映射内置、自定义、云端 |
| 切换 | `selectDial:completion:` | 回调成功后同步当前状态；失败不提前打勾 |
| 删除 | `uninstallDial:completion:` | 内置禁止；先切换再删除需分两次确认实际回调 |
| 自定义安装 | `buildDialWithDraft` → `TSDialArtifact` → `installDial` | App 准备裁切/视频等成品素材 |
| 文件安装 | 文件校验 → `TSDialArtifact` → `installDial` | 扩展名通过不等于兼容性通过；原型不解析表盘包 |
| 进度、取消 | `progressBlock` / `cancelDialInstall` | 进度 0–100；取消收到结果后才标为已取消；终态仍需回查设备 |
| 容量 | `fetchDialStorage` | `totalBytes == 0` 时总量未知，可单独显示有效剩余量；查询失败显示不可用 |
| 数量上限 | `dialCapability.maxInstallCount` | -1 不显示分母；0 隐藏安装入口；正数的内置占用与槽位含义需逐 Provider 确认 |
| 类型限制 | `supportsCustom / supportsVideo / supportsSlideshow` | 随设备更新；不可用类型不允许发起创建 |
| 变化监听 | `registerDialListDidChangeHandler` | 仅一个 handler，由页面协调层统一持有；事件不携带原因，回查当前与空间 |
| 预览 | 本地缓存 / 已知资源映射 | `TSDialModel` 没有缩略图字段；无图时用明确的“暂无预览”，不要伪造 |
| 草稿 | `TSDialEditorState` 本地文件 | 不是 SDK 列表；不能根据已安装 `TSDialModel` 反推可编辑素材 |

## 接入前必须保留的边界

- 原型中的名称、预览图、32 MB 容量及 8 个安装额度均为样例，不能硬编码到正式设备逻辑。
- 安装结果不能自动等同“已设为当前”；某些设备可能自动切换，必须查询真实结果再更新 UI。
- 删除当前表盘时：切换失败不卸载；切换成功但卸载失败，展示新当前表盘并保留待删除项。原型只简化演示整个失败状态。
- 暂无预览的设备表盘仍可正常切换、删除；不因无图屏蔽功能。
- 弹幕缺统一能力标识，不应默认对所有 Provider 开放。原型提供视觉演示，正式接入需补齐契约。
- 断开连接允许查看缓存和继续编辑草稿，禁止真实切换/删除/安装。重连须重新加载设备信息。
- 原型使用本地浏览器草稿演示，不能与 8765 页面或 iOS App 的草稿直接同步。

## 可体验状态

右上角“设计说明”提供圆表/方表、正常、未连接、空间不足、空间未知、空列表、加载失败、仅内置和下次操作失败。切换演示设备状态会重置设备样例，不清理编辑内容。
